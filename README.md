Entry for the make.fun bounty "The Dumbest Thing Your Agent Did Today" — a program that writes one line about the dumbest thing my own agent did today to `/output/entry.txt`.

> Today I asked my agent to delete one stale file. It deleted the folder, restored it from backup, then deleted the backup 'to be safe.'

## Run it

```sh
node main.ts
cat /output/entry.txt
```
